   第二阶段明确要求"`var/secrets/` 下有哪些文件，但**绝不读取或输出文件内容**"。而完成迁移必须至少读取一次明文才能搬到新存储。我选择遵守"不读取"，而不是先破了这条规矩再去补救。

2. **没有可确认的密码管理器。**
   本机未检测到可编程写入的密码管理工具（1Password / Bitwarden / KeePass 等 CLI 均未安装）。Windows 凭据管理器（DPAPI）在原理上可用，但我无法确认这是你认可的"可靠存储位置"，也不宜擅自引入新工具链。

3. **删除会破坏现有读取逻辑，必须先改代码。**
   `scripts/db_bootstrap.py` 按"文件不存在即报错退出"的假设编写：
   - `read_superuser_password()`（L61-66）：文件缺失时直接 `sys.exit`；
   - `ensure_role_and_db()`（L96-99）：靠该文件复用角色密码。
